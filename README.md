# dytica-data

Dytica（星導ショウ・叢雲カゲツ・小柳ロウ・伊波ライ）4人の**非公式**ファンサイトが読むデータです。
ご本人・運営とは関係ありません。ご本人・運営へのお問い合わせはお控えください。

3か所のデータを点検してまとめ、GitHub Pages で配っています。

| 元のデータ | 中身 |
|---|---|
| Dytica のシート | カゲツ・ロウ・ライの動画と、ほかの人の枠への出演（他枠） |
| ショウケースのシート | ショウの動画（[ショウケース](https://sho-case.netlify.app/) と同じもの） |
| [MECHATU-NE ARCHIVE](https://mechatu-ne-archive.netlify.app/) | 楽曲 |

## 更新のしかた

`export/build.js` が読んで、点検して、`out/` に書き出します。
GitHub Actions（`.github/workflows/publish.yml`）が3時間おき（と、シートが変わったとき）に動かします。

```
node export/build.js                   公開中のシートから書き出す
node export/build.js --from <フォルダ>   手元のファイルから書き出す（試すとき）
node export/build.js --prev <フォルダ>   前回の公開の代わりに、手元の前回の out/ と比べる（試すとき）
```

外の部品は使っていません（Node.js 24 だけで動きます）。

### 点検の決まり

| 起きたこと | どうするか |
|---|---|
| シートが読めない・見出しが無い・件数が前回の9割を切った | **止める**（公開しない。前のデータのまま）。GitHub からメールが届く |
| 1行だけの問題（公開日が読めない、など） | **その行だけ外して公開**し、`report.json` と実行の Summary で知らせる。前回に無かった問題のときだけ、メールが届く |
| 出演に分からない名前がある、など | その項目だけ捨てて公開し、知らせる |

## ファイル

| ファイル | 中身 |
|---|---|
| `meta.json` | 書き出した時刻・件数・4人の名前と色・各ファイルの印（`hash`） |
| `videos/latest.json` | 新しい順に60件（トップ用） |
| `videos/sho.json` など | その人が出ている動画（`sho` `kagetsu` `rou` `rai`） |
| `videos/dytica.json` | 2人以上が出ている動画 |
| `videos/all.json` | すべての動画（「全員」と検索用） |
| `songs.json` | 4人の誰かが歌っている楽曲（歌ってみた・オリジナル） |
| `report.json` | 点検の結果 |
| `cache/hosts.json` | 他枠の持ち主の名前の控え（書き出しが次回に使う。サイトは使わない） |
| `wiki/items.json` | 非公式 Wiki の「動画一覧」から読み取った動画（カゲツ・ロウ・ライ）。シートの Apps Script が差分を作るのに使う。サイトは使わない |

### 非公式 Wiki の一覧（`export/wiki.js`）

Wiki の前にいる Cloudflare が Google のサーバー（Apps Script）からの読み込みを断るので、ここで週1回読んでいます。
続けて読むと断られる（429）ので、ページの間を8秒空けます。読めなかったページは前回の中身を使い、公開は止めません。

```
node export/wiki.js --out out            前回から6日以上たっていれば読み直す
node export/wiki.js --out out --force    すぐ読み直す
```

**読むときは、先に `meta.json` を読み、各ファイルを `?v=<hash>` を付けて読んでください。**
GitHub Pages は10分ほど手元に残るので、そのままだと古いファイルが出ることがあります。

### 動画（`videos/*.json`）

配列で、新しい順に並んでいます。1件の形：

| 項目 | 意味 | 例 |
|---|---|---|
| `i` | YouTube の動画ID | `"0M4RZW..."` |
| `t` | タイトル | |
| `d` | 公開日（日本時間）。配信は始まった日 | `"2026-10-14"` |
| `s` | 開始時刻（日本時間・配信だけ） | `"21:30"` |
| `l` | 長さ（秒） | `6399` |
| `h` | 枠の持ち主（4人のとき） | `"kagetsu"` |
| `o` | 枠の持ち主の名前（4人以外＝他枠のとき） | `"赤城ウェン"` |
| `m` | 出ている4人（決まった順：sho → kagetsu → rou → rai） | `["sho","kagetsu"]` |
| `c` | 一緒に出ている4人以外の人 | `["緋八マナ"]` |
| `g` | カテゴリ | `"Apex"` |
| `k` | 種別：`L` 配信／`S` Shorts／`V` 動画 | `"L"` |
| `d3` | 3D なら `1` | |
| `sg` | 歌ったパートがあれば `1` | |
| `p` | 同じ企画の印。4人がそれぞれの枠で同じコラボを配信したとき、同じ値（代表の動画ID）が入る。一覧ではこれでまとめる | |

`h` か `o` のどちらかが入ります。値が無い項目は、項目ごと省いています。

### 楽曲（`songs.json`）

| 項目 | 意味 |
|---|---|
| `i` | YouTube の動画ID |
| `t` | 曲名 |
| `o` | 原曲 |
| `d` | 公開日（日本時間） |
| `m` | 歌っている4人 |
| `v` | 歌唱（表示用の文字。4人以外も含む） |
| `k` | `cover`（歌ってみた）／`original`（オリジナル） |
| `b` | 購入・配信のページ |

### 4人の色（`meta.json` の `members`）

| 項目 | 使いどころ |
|---|---|
| `mark` | 印・帯 |
| `textLight` / `textDark` | 明るい表示／暗い表示での文字 |
| `onMark` | `mark` の上に載せる文字 |

⚠️ `mark` をそのまま文字に使わないでください。伊波ライの `#DCFF50` は白地でほぼ見えません。
