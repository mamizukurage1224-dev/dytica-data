# dytica-data

MECHATU-A（Oriens：赤城ウェン・宇佐美リト・佐伯イッテツ・緋八マナ／Dytica：伊波ライ・小柳ロウ・星導ショウ・叢雲カゲツ）8人の**非公式**ファンサイトが読むデータです。
ご本人・運営とは関係ありません。ご本人・運営へのお問い合わせはお控えください。

3か所のデータを点検してまとめ、GitHub Pages で配っています。

| 元のデータ | 中身 |
|---|---|
| Dytica のシート | ショウ以外の7人の動画と、ほかの人の枠への出演（他枠）・にじさんじ公式切り抜きチャンネルの動画 |
| ショウケースのシート | ショウの動画と切り抜き・ショウが出たライブ（[ショウケース](https://sho-case.netlify.app/) と同じもの） |
| [MECHATU-NE ARCHIVE](https://mechatu-ne-archive.com/) | 楽曲 |

## 更新のしかた

`export/build.js` が読んで、点検して、`out/` に書き出します。
GitHub Actions（`.github/workflows/publish.yml`）が3時間おきに動かします（すぐ出したいときは Actions タブの Run workflow。シートが変わったときに動かす仕組みは、まだ作っていません）。

```
node export/build.js                   公開中のシートから書き出す
node export/build.js --from <フォルダ>   手元のファイルから書き出す（試すとき）
node export/build.js --prev <フォルダ>   前回の公開の代わりに、手元の前回の out/ と比べる（試すとき）
```

外の部品は使っていません（Node.js 24 だけで動きます）。

### 点検の決まり

| 起きたこと | どうするか |
|---|---|
| シートが読めない・見出しが無い・件数が前回の9割を切った | **止める**（公開しない。前のデータのまま）。GitHub からメールが届く |
| 1行だけの問題（公開日が読めない、など） | **その行だけ外して公開**し、`report.json` と実行の Summary で知らせる。前回に無かった問題のときだけ、メールが届く |
| 出演に分からない名前がある、など | その項目だけ捨てて公開し、知らせる |
| 消された・非公開になった動画（YouTube のサムネイルが 404） | その動画を外して公開し、「お知らせ」に出す。シートの行はそのまま |

### 非公式 Wiki の一覧（`export/wiki.js`）

Wiki の前にいる Cloudflare が Google のサーバー（Apps Script）からの読み込みを断るので、ここで週1回読んでいます。
続けて読むと断られる（429）ので、ページの間を8秒空けます。読めなかったページは前回の中身を使い、公開は止めません。

```
node export/wiki.js --out out            前回から6日以上たっていれば読み直す
node export/wiki.js --out out --force    すぐ読み直す
```

### これからの配信（`export/upcoming.js`）

Holodex に、4人のチャンネルと「4人の名前が入っているほかの人の配信」の予定をまとめて問い合わせます（1回）。
キーは GitHub の Secrets（`HOLODEX_API_KEY`）に置いています。読めなかったときは前回の一覧を残し、公開は止めません。

```
HOLODEX_API_KEY=… node export/upcoming.js --out out   Holodex から取る
node export/upcoming.js --out out --from <ファイル>     手元に控えた Holodex の返事から作る（試すとき）
```

載せないもの：フリーチャットの枠、30日より先の予定、予定の時刻を6時間過ぎても始まっていない枠、
X の告知などから作られた予定（YouTube の動画IDが無いもの）。

**読むときは、先に `meta.json` を読み、各ファイルを `?v=<hash>` を付けて読んでください。**
GitHub Pages は10分ほど手元に残るので、そのままだと古いファイルが出ることがあります。

### 動画（`videos/*.json`）

配列で、新しい順に並んでいます。1件の形：

| 項目 | 意味 | 例 |
|---|---|---|
| `i` | YouTube の動画ID | `"0M4RZW..."` |
| `t` | タイトル | |
| `d` | 公開日（日本時間）。配信は始まった日 | `"2026-10-14"` |
| `s` | 開始時刻（日本時間・配信だけ）。ショウの行は Holodex から補う（ショウケースのシートに開始時刻の列が無いため。シートの日付と Holodex の開始日が違うものには入れない） | `"21:30"` |
| `l` | 長さ（秒） | `6399` |
| `h` | 枠の持ち主（4人のとき） | `"kagetsu"` |
| `o` | 枠の持ち主の名前（4人以外＝他枠のとき） | `"赤城ウェン"` |
| `m` | 出ている8人のうちの人（決まった順：wen → rito → ittetsu → mana → rai → rou → sho → kagetsu。MECHATU-NE と同じ） | `["rai","kagetsu"]` |
| `x` | 8人のほかにも出ている人がいれば `1`（ソロ・コラボの見分けに使う）。⚠️ 名前は入れない（2026-10-29。シートのコラボ相手は概要欄に無い回もあり、正しく分かりきらないため） | |
| `g` | カテゴリ | `"Apex"` |
| `k` | 種別：`L` 配信／`S` Shorts／`V` 動画。シートで Shorts でも、YouTube で Shorts でなかったものは `V`（cache/shorts.json） | `"L"` |
| `d3` | 3D なら `1` | |
| `sg` | 歌ったパートがあれば `1` | |
| `cl` | クリップなら `1`。本人のチャンネル以外で投稿された、配信ではない動画（動画・Shorts）のうち、にじさんじ公式切り抜きチャンネルの動画・ショウケースの「切り抜き」タブにある動画・タイトルに「切り抜き」（切抜き）「【漫画】」「にじさんじハイライト」があるもの・ほかのライバーのチャンネルの Shorts（踊ってみた・歌ってみたなどと、にじさんじ公式チャンネルは除く）。Oriens のユニットのチャンネルの動画は除く。Dytica のシートの「クリップ」の列に ○・× があれば、そちらが先。サイトはアーカイブと分けて出す | |
| `dt` | 同じ日に、先に出る同じサムネイルの絵の動画ID（同じ人が同じサムネイルを使った配信など）。カレンダーのマスで同じ絵を2回出さないのに使う。楽曲（songs.json）にも付く | |
| `gm` | 同じゲームの印（Holodex のゲーム名。例 `BOMBANANA!`）。主に単発のゲームの配信だけに入る（決め方は export/build.js の markSameGames） | |
| `ga` | ゲーム名（Holodex のゲーム名）。ゲームの分類が付いた配信すべてに入る（雑談・歌枠などは入らない）。アーカイブをゲームで絞るのに使う（2026-10-30） | `"apex"` |
| `p` | 同じ企画の印（代表の動画ID）。8人がそれぞれの枠で同じコラボを配信したときと、ほかの人の枠の同じ企画（8人のだれかの枠と配信の時間が重なっていて、その人が出ているもの。ゲーム名が違うもの・逆凸などは除く）に同じ値が入る。代表はいつも8人の枠。サイトでは、8人の枠の配信はそれぞれ一覧に出し、ほかの人の枠と枠の立て直しの短いほうは詳細の「ほかの視点」に出す（2026-10-30 から）。組み合わせ・周年記念の数では1回と数える。決め方は export/build.js の groupSameCollab | |

`h` か `o` のどちらかが入ります。値が無い項目は、項目ごと省いています。

### ディスコグラフィ（`discography.json`）

配列で、新しい順に並んでいます。1行＝シートの1行（版ちがいは別々の行）。同じ販売ページの行は1件にまとめ、`m` を合わせています。

| 項目 | 意味 | 例 |
|---|---|---|
| `t` | タイトル | `"On-Deck!　通常盤"` |
| `d` | 発売日・配信開始日（日本時間）。分からないときは無い | `"2026-07-22"` |
| `y` | 年（`d` が無いときだけ） | `"2026"` |
| `k` | 種別 | `"CD"` `"Blu-ray"` `"デジタル"` |
| `b` | 販売ページ | |
| `v` | 関連動画の YouTube の動画ID | |
| `n` | 備考 | |
| `m` | 参加した4人 | `["sho","kagetsu","rou","rai"]` |

読めなかったときは書き出しを止めず、前回の公開のものを使います。

| 項目 | 意味 | 例 |
|---|---|---|
| `t` | 記事タイトル | |
| `u` | 記事のページ | |
| `d` | 日付（日本時間）。読めないときは無い | `"2026-09-18"` |

読めなかったときは書き出しを止めず、前回の公開のものを使います。

### ライブ（`lives.json`）

配列で、新しい順に並んでいます。同じ ID の公演が両方のシートにあるときは、ショウケースのほうを使います。

| 項目 | 意味 | 例 |
|---|---|---|
| `id` | 公演の ID（シートの ID。URL の `#/lives?e=` に使う） | `"od"` |
| `t` | 公演の名前 | |
| `d` | 日付 | `"2026-10-10"` |
| `pl` `tm` `f` | 会場・開始時刻・形態（書いたまま）。無ければ無い | `"OPEN 16:30 / START 18:00"` |
| `a` `at` | アーカイブの動画ID と、何秒から開くか（無ければ無い） | `"BfdLgs1PL6I"` `1668` |
| `u` | 公式サイトの公演のページ | |
| `m` | 出た8人 | `["ittetsu","sho"]` |
| `o` | 8人以外の出演者の名前（いなければ無い） | `["三枝明那"]` |
| `sl` | セットリスト。`{ n: 番号（メドレーは "24-1"）, t: 曲名, s: 歌った人（8人は key、ユニットは名前、ほかの人は名前のまま）, m: 歌った8人（ユニットは中の人に広げる）, v, at: その曲のところの動画ID と秒 }` | |
| `vids` | 関連動画 `{ t, v }` | |
| `links` | ライブレポート・特集記事 `{ g: 種別, t, u }` | |
| `rel` | リリース `{ t, u }` | |

写真・ポスト・グッズは読みません。読めなかったときは書き出しを止めず、前回の公開のものを使います。

### 周年記念（`stats.json`）

`{ today, all, members }`。`all` は8人の配信、`members` は人ごと（key → 同じ形）。

| 項目 | 意味 |
|---|---|
| `n` | 配信の本数（同じ企画の別視点は1本。ほかの人の枠に出た回も入れる。クリップ・配信予定は入れない） |
| `h` | 合わせた長さ（時間。四捨五入） |
| `y` | 年ごと `{ "2023": { n, h }, ... }` |

### これからの配信（`upcoming.json`）

`{ "items": [...] }` の形で、`items` は始まる順に並んでいます。読めなかったときは `error` に理由が入ります（`items` は前回の残り）。

| 項目 | 意味 | 例 |
|---|---|---|
| `i` | YouTube の動画ID | |
| `t` | タイトル | |
| `s` | 始まる時刻（配信中なら始まった時刻）。世界時の ISO 形式なので、日本時間に直して出す | `"2026-10-18T09:00:00.000Z"` |
| `live` | 書き出したときに配信中なら `1` | |
| `h` / `o` | 枠の持ち主（4人のときは `h` にキー、ほかの人は `o` に名前） | `"にじさんじ"` |
| `m` | 出ている8人のうちの人 | `["sho","kagetsu","rou","rai"]` |

⚠️ 3時間おきの書き出しなので、`live` や一覧は最大3時間ほど古いことがあります。始まる時刻を過ぎたものは、見る側で「予定の時刻を過ぎました」などと添えてください。

| 項目 | 使いどころ |
